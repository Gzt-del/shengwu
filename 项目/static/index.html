模块说明

      

        
序列概览组成统计、GC 含量、滑窗 GC / GC-Skew 曲线

        
序列比对Needleman-Wunsch 全局 / Smith-Waterman 局部比对，含 DP 矩阵热图

        
ORF 与翻译双链六框翻译、ORF 查找、蛋白质分子量 / 等电点等理化性质

        
酶切图谱26 种常用限制性内切酶位点搜索与片段分析

        
系统发育遗传距离矩阵 + 邻接法（NJ）建树，导出 Newick

        
序列聚类k-mer 距离 + PCoA 降维 + k-means 无监督聚类
